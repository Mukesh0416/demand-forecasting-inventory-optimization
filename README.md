# AI-Powered Demand Forecasting & Inventory Optimization

An end-to-end supply chain analytics and machine learning project for
retail demand forecasting and inventory optimization.

## Project Status

🚧 In Development

## Problem

Retail businesses need to forecast product demand accurately and
maintain sufficient inventory while minimizing stockouts and excess
inventory.

## Objectives

- Analyze historical retail demand
- Identify demand trends and seasonality
- Build baseline forecasting models
- Build machine learning forecasting models
- Compare forecasting performance
- Calculate safety stock
- Calculate reorder points
- Recommend replenishment quantities
- Identify stockout and overstock risks
- Build an interactive supply-chain dashboard

## Technology

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SQL
- Power BI
- Git & GitHub

## Dataset

M5 Forecasting dataset containing historical retail sales,
calendar information, and product pricing data.
